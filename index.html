iPhone のホーム画面に置く

  1. 上のどれかを Safari でひらく
  2. 共有（□に↑。無ければ右下の「…」の中）→「ホーム画面に追加」
  3. 「Webアプリとして開く」はオンのまま「追加」
  4. ホーム画面からひらいて、最初に一度だけ GitHub のトークンを貼る（ほかのアプリにも同じトークン）
